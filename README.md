# Integra · Integración metabólica

Recurso docente de Bioquímica (Medicina, Universidad de Granada) para estudiar la integración metabólica en el postprandio, el ayuno, el ejercicio y en situaciones patológicas (ayuno tardío, inanición, resistencia a la insulina y cetoacidosis diabética).

**Abrir la aplicación:** https://ctp-granada.github.io/Integra/

## Contenido del repositorio
- `index.html`, `app.js`, `chunk-*.js`: la aplicación ya compilada, que es lo que publica GitHub Pages.
- `codigo-fuente/`: proyecto React + TypeScript + Vite para modificarla (`npm install` y `npm run dev`).
- `codigo-fuente/CAMBIOS_REVISION_BIOQUIMICA.md`: registro de la revisión bioquímica y de los cambios.
